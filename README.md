# EVRENİN EN CİDDİ ÇAY DEMLEME PROTOKOLÜ

> **UYARI:** Bu belge şaka değildir. Bu belge bir şakayı ciddiye alma sanatıdır. Lütfen kravat takarak okuyunuz.

## 1. Amaç ve Kapsam

Bu yazılım, bir bardak çayın *gerçek* demlenme süresini hesaplar. Hesap; Planck sabiti, komşunun balkonundaki çamaşır ipinin salınım frekansı, senin o gün kaç kere "abi" dediğin ve evrenin o anki entropi hissiyatı üzerinden yapılır.

Herkes çay demler. 
Ama çok az kişi çayı *anayasal* olarak demler.

## 2. Kurulum

```bash
python3 cay_protokolu.py
```

Bağımlılık yoktur. Çünkü evren zaten yeterince bağımlıdır.

## 3. Kullanım

Program senden üç şey ister:
1. Bugün kaç kere "abi" dedin?
2. Çay siyah mı, yeşil mi, yoksa "annemin karışımı" mı?
3. Komşunun balkonu açık mı?

Sonra seni 3 ila 17 saniye arasında bilimsel olarak bekletir. Beklerken ekrana çıkan cümleler rastgele değildir; hepsi **Uluslararası Çay Termodinamiği Komitesi** tarafından onaylanmıştır.

## 4. Bilimsel Temel (ciddi kısım)

Demlenme süresi şu formülle bulunur:

```
t = (abi_sayisi * 0.42) + (balkon_acik ? 1.7 : 0.3) + rastgele_kuantum_titreme
```

Formül peer-review geçmemiştir. Peer'ler çay içiyordu.
